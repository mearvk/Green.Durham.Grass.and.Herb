# Contacts

The `contacts/` tree is a distinct reference and public-contact collection. It should not be treated as an authorization database or as a source of private identity data.

## Organization

The existing structure includes categories such as `mayorial`, `national`, `senatorial`, `general.assembly`, and `house.of.representatives`, together with country-specific reference directories.

## Maintenance rules

- Preserve the source category and jurisdiction in each contact document.
- Prefer official public contact information.
- Record the source and date when practical.
- Do not add private personal information merely because it is discoverable.
- Keep contact/reference material separate from application credentials and runtime logs.
- Review stale links and obsolete offices periodically.

## Political neutrality

Contact documentation is an organizational/reference function. It does not itself confer endorsement, authority, office, legal status, or access to application services.
